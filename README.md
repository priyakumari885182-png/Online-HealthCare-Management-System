# HealthCare Pro — Functional Frontend Prototype

## Run
Open `index.html` in Chrome/Edge, or use VS Code Live Server.

## Working modules
- Login / Sign Up demo
- Doctor search and specialty filtering
- Appointment booking and cancellation
- Medicine reminders and dose tracking
- Family profiles and profile switching
- Health timeline
- Emergency support panel
- Dashboard statistics
- LocalStorage persistence

## Differentiators
1. Smart Doctor Match / specialty-based discovery
2. Medicine reminder + dose tracking
3. Family healthcare profiles
4. Unified health timeline
5. Emergency quick-access workflow
6. Privacy-first local demo storage

## Important
This is an academic/demo application. It does not connect to a real hospital, doctor, payment gateway, medical database, or emergency service. Do not enter real sensitive medical information.
